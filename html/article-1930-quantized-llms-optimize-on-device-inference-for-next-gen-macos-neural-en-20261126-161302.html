FIELD NOTE

Understanding Quantization in LLMs

Quantization is a process that constrains input values, moving from continuous sets to discrete, measurable increments. In the context of LLMs, this technique reduces the computational and memory costs required for running inference by representing model weights differently.

  • Quantization means subdividing something into small, measurable increments.
  • It constrains an input from a continuous set of values to a discrete set.
