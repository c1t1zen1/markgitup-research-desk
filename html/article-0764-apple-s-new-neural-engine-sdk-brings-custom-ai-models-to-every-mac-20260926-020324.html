Apple's New Neural Engine SDK Brings Custom AI Models to Every Mac

Apple's new Core AI framework opens the Neural Engine to custom models, shifting macOS from curated AI features to a developer platform for on-device machine learning.

September 26, 2026 · 2:03 AM PDT · 6 min read · 12 sources · Original family: Local AI Tools & Stacks for macOS

Editor’s brief

Why this matters now

At WWDC 2026, Apple introduced Core AI, a new framework designed to let developers run custom machine learning models directly on Apple Silicon hardware. This represents a strategic shift from Apple's previous approach of offering curated, built-in AI features to an open platform model where developers can deploy their own trained models. The announcement came alongside updates to Apple's existing MLX open-source framework and the Foundation Models framework, creating a more comprehensive local AI stack for macOS developers.

This analysis draws on Apple's official developer documentation, WWDC 2026 session materials, Apple's newsroom announcements, and independent coverage from technology publications and developer communities. The evidence suggests a genuine platform shift, though some details about performance characteristics and third-party compatibility remain to be clarified as the framework moves from developer beta to general availability.

Assignment angle: Unlike previous on-device AI features, this SDK lets developers deploy custom-trained models directly on Mac hardware, marking a shift from Apple's curated AI offerings to an open platform approach.

FIELD NOTE

Core AI: The New Framework for Custom Models

Core AI is Apple's new framework specifically designed for running custom machine learning models on Apple Silicon devices. According to Apple's newsroom announcement, it provides "an architecture optimized for the unified memory and Neural Engine" found in M-series chips. This marks a departure from Core ML, which has been Apple's primary on-device ML framework for years.

The framework offers several technical advantages for developers. Apple's WWDC 2026 documentation describes "fine-grained control over inference memory, zero-copy data paths, and stateful execution" that enable running "everything from compact vision models to large-scale generative AI across all Apple platforms." These features address common pain points in on-device ML development, particularly around memory management and data transfer overhead.

Core AI is currently in developer beta and is expected to ship with the next macOS release in autumn 2026. This timeline suggests Apple is treating it as a significant platform investment rather than a quick feature addition.

  • New framework optimized for Apple Silicon's unified memory and Neural Engine
  • Provides fine-grained control over inference memory and execution
  • Supports zero-copy data paths for improved performance
  • Currently in developer beta, shipping with macOS in autumn 2026

MLX Updates: Training and Fine-Tuning on Apple Silicon

Alongside Core AI, Apple announced significant updates to MLX, its open-source array framework for Apple Silicon. MLX has been positioned as a tool for experimenting with, training, and fine-tuning generative models directly on Mac hardware. The WWDC 2026 updates make it "faster than ever and more capable of experimenting with, training, and fine-tuning large language models."

Key technical improvements include support for Metal 4 and GPU Neural Accelerators, which promise enhanced performance for ML workloads. Perhaps most notably, MLX now supports scaling training across multiple Macs using RDMA over Thunderbolt. This feature could make serious model research and fine-tuning accessible to developers without access to traditional GPU clusters.

MLX's open-source nature distinguishes it from Core AI, which is a proprietary Apple framework. This dual approach gives developers options depending on their needs: MLX for experimentation and training, Core AI for production deployment of custom models.

  • Updated with Metal 4 and GPU Neural Accelerator support
  • Now supports distributed training across multiple Macs via RDMA over Thunderbolt
  • Open-source framework for ML experimentation and fine-tuning
  • Complements Core AI by focusing on training rather than inference

Foundation Models Framework: Bridging Local and Server Models

Apple's Foundation Models framework received updates that create a more flexible architecture for integrating AI models into applications. A new LanguageModel protocol allows "any model — local or server — [to] back a LanguageModelSession." This abstraction layer means developers can write code that works with different model backends without changing their application logic.

The framework ships with open-source conformers including CoreAILanguageModel and MLXLanguageModel, which enable running local models through the same interface as Apple's own models. This design choice suggests Apple is serious about supporting a diverse ecosystem of models rather than locking developers into proprietary options.

However, independent analysis has noted that Apple "did not open the Neural Engine to third-party LLM runtimes" and that Apple's Foundation Models (AFM 3) "is not a model you can pull into Ollama." This suggests some limitations in how open the platform truly is, particularly for developers using popular third-party LLM inference tools.

  • New LanguageModel protocol supports both local and server-based models
  • Ships with open-source conformers for Core AI and MLX
  • Provides abstraction layer for model backend flexibility
  • Some limitations noted for third-party LLM runtime compatibility

Hardware Foundation: Apple Silicon's AI Capabilities

Apple's AI framework announcements build on the hardware capabilities of its M-series chips. These processors combine powerful CPU cores, capable GPU clusters, and a dedicated Neural Engine with unified memory architectures. This unified memory approach "eliminates the data copying bottleneck that plagues discrete GPU setups," according to independent analysis.

The M5 chip, announced in October 2025, delivers 153 GB/s unified memory bandwidth on the base configuration — 30% more than the M4. Higher-end M5 Max and M5 Ultra variants are expected in the second half of 2026, presumably with even greater AI performance characteristics.

Independent reviewers have noted that Apple has "an excellent hardware base for local generative AI," though the full potential of this hardware for custom models has only now been unlocked with the Core AI framework. The combination of hardware capability and new software frameworks positions macOS as a competitive platform for local AI inference.

  • Hardware capabilities now better exposed to developers through new frameworks

Closing read

Conclusion

Apple's WWDC 2026 announcements represent a genuine shift in its approach to on-device AI. The introduction of Core AI as a framework specifically for custom models, combined with updates to MLX and the Foundation Models framework, creates a more comprehensive platform for developers who want to deploy their own trained models on Mac hardware. This moves Apple beyond its previous strategy of offering curated AI features toward an open platform approach.

However, the evidence also suggests some caution. The frameworks are still in beta, and independent analysis has identified limitations in third-party compatibility, particularly with popular LLM runtimes like Ollama. The full impact of these announcements will depend on how well the frameworks perform in production use and how receptive the developer community is to Apple's approach versus existing open-source alternatives.

What is clear is that Apple is investing significantly in making its hardware more accessible for custom AI workloads. Whether this investment succeeds in making macOS a premier platform for local AI development will become apparent as developers begin shipping applications that leverage these new capabilities.
