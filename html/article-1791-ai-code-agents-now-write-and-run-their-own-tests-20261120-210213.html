AI Code Agents Now Write and Run Their Own Tests

AI coding agents are shifting from writing code to autonomously generating, running, and refining tests, closing the loop between implementation and validation.

Why this matters now

This article examines the emerging capability of AI code agents to write and execute their own tests. The analysis draws on documentation from JetBrains, technical guides from TestGrid and Augment Code, research from SonarSource, and academic work on agent control policies. The evidence suggests a transition from AI as a code-completion tool to AI as an autonomous development loop that can propose, test, and refine its own work.

FIELD NOTE

The Shift from Code Generation to Test Autonomy

AI coding agents have long been able to generate code that compiles and passes basic tests. However, a new capability is emerging: agents that can autonomously generate, execute, and refine their own test suites. This represents a fundamental shift in how AI participates in the development process, moving from a tool that writes code to one that validates its own work.

  • Agents now generate tests from source code by parsing programs into Abstract Syntax Trees
  • The read-write-build-execute loop allows agents to compile and validate each candidate test
  • AI can regenerate or extend tests as requirements evolve

How AI Agents Generate and Run Tests

The technical process involves several stages. First, the agent parses the input project into an AST and transforms it into relational schemas representing classes, methods, and dependencies. It then generates candidate tests, compiles them, and executes them in a loop. When tests fail, the agent can refine either the test or the implementation code. JetBrains' AI Assistant documentation confirms this capability, noting that the tool analyzes both code and context to recommend tests that provide insights into behavior.

  • Agents parse source code into ASTs and retrieve cross-file dependencies
  • Tests are compiled and validated in a read-write-build-execute loop
  • AI Assistant analyzes code segment context to recommend behavior-revealing tests

FIELD NOTE

The Quality Gap: What AI Tests Miss

Despite these advances, AI-generated tests have limitations. SonarSource research indicates that AI coding agents generate code that 'compiles, passes basic tests, and looks reasonable in isolation,' but often fails to adhere to project-specific coding standards. This suggests that while AI can validate functional correctness, it may miss deeper quality concerns such as maintainability, security patterns, and architectural consistency.

  • AI-generated code often passes basic tests but misses project-specific standards
  • Functional correctness is validated, but deeper quality concerns may be overlooked
  • The gap between 'compiles and passes tests' and 'production-ready' remains

Research on Agent Control and Security

Academic research is addressing the challenges of autonomous AI agents. Work by Prof. Dr. Guido Salvaneschi's Programming Group demonstrates that control policies can be generated automatically from source code with 80.9% accuracy. This research is particularly relevant as AI agents gain autonomy over test generation and execution, raising questions about what tests they write and how they interpret results.

Closing read

Conclusion

The evidence supports a clear trend: AI code agents are evolving from passive code generators to active participants in the development loop that can write, run, and refine their own tests. This capability is documented across multiple sources, from JetBrains' product documentation to technical guides and academic research. However, the quality of AI-generated tests remains a concern, with SonarSource noting that agents often produce code that passes basic tests but misses project-specific standards. The research on agent control policies suggests that the field is actively working to address the security and reliability challenges that come with greater agent autonomy. While the capability is real and documented, its production readiness varies, and the gap between functional test coverage and comprehensive quality assurance remains significant.

Five takeaways

  • AI code agents can now autonomously generate, compile, and execute tests from source code

  • AI-generated tests often pass basic validation but may miss project-specific standards
  • Research shows control policies can be auto-generated with 80.9% accuracy
  • JetBrains' AI Assistant already offers test generation based on code context analysis
