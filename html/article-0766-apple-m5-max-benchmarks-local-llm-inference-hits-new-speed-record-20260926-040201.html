Apple M5 Max Benchmarks: Local LLM Inference Hits New Speed Record

Fresh benchmarks show the Apple M5 Max delivering up to 65 tokens per second on 8B models and 22 on 70B, setting new local LLM inference speeds on Apple Silicon.

September 26, 2026 · 4:02 AM PDT · 5 min read · 12 sources · Original family: M Series Apple Silicon LLM Inference

Editor’s brief

Why this matters now

The Apple M5 Max chip is establishing new performance benchmarks for local large language model inference on Apple Silicon. Multiple independent benchmarks and Apple's own research indicate significant speed improvements over previous generations, with the M5 Max delivering up to 65 tokens per second on 8B parameter models and 22 tokens per second on 70B models. This performance leap comes from architectural improvements including 40 Neural Accelerators operating in parallel with direct access to a unified memory pool, eliminating data movement overhead between compute units. The evidence comes from a mix of Apple's official MLX research, independent benchmarking sites, community testing on platforms like Reddit, and detailed performance guides published throughout 2026.

Assignment angle: Fresh performance benchmarks show the M5 Max chip dramatically accelerating local LLM inference, a concrete data-driven angle not covered in prior pieces.

FIELD NOTE

Performance Benchmarks: M5 Max vs. Previous Generations

The M5 Max demonstrates substantial performance gains over its predecessor. Independent benchmarks show the M5 Max achieving 55-65 tokens per second on 8B parameter models and 18-22 tokens per second on 70B models, compared to the M5 Pro's 45-50 and 12-16 tokens per second respectively. One analysis found the M5 Max delivers approximately 28% higher tokens per second than the M4 Max for local LLM workloads. Apple's own research comparing MLX inference on M5 versus M4 MacBook Pro systems shows measurable speedups in both time-to-first-token and subsequent token generation across different model sizes. These improvements are particularly notable for larger models where memory bandwidth and parallel processing capabilities become critical bottlenecks.

  • M5 Max: 55-65 tok/s on 8B models, 18-22 tok/s on 70B models
  • M5 Pro: 45-50 tok/s on 8B models, 12-16 tok/s on 70B models
  • Approximately 28% faster than M4 Max for local LLM inference
  • Apple's MLX research confirms speedups in both TTFT and token generation

Architecture and Memory Advantages

The M5 Max's performance gains stem from its architectural design, particularly its memory subsystem and neural processing capabilities. The chip features an 18-core CPU architecture and up to a 40-core GPU, with each GPU core containing a Neural Accelerator that operates in parallel with direct access to the unified memory pool. This design eliminates data movement overhead between compute units during inference workloads. The system offers up to 128GB of unified memory with 614GB/s bandwidth, enabling it to load and run models that typically require large GPU setups. This memory capacity is particularly valuable for running larger open-weight models locally, including 90B+ parameter models that were previously impractical on laptop-class hardware. The combination of high memory bandwidth and parallel neural processing creates a compelling platform for local AI inference.

  • 18-core CPU with up to 40-core GPU architecture
  • 40 Neural Accelerators operating in parallel
  • Up to 128GB unified memory with 614GB/s bandwidth
  • Direct memory access eliminates data movement overhead

Real-World Model Performance and Thermal Characteristics

Community testing and detailed benchmarks reveal how the M5 Max performs with specific models in real-world conditions. Tests with mlx_lm, Apple's MLX inference stack, show the system handling various quantized models effectively. One detailed test reported Qwen 3.5 122B-A10B at 4-bit quantization achieving approximately 66, 61, and 55 tokens per second at 4K, 16K, and 32K context lengths respectively. Another test showed Qwen2.5 VL 7B delivering 0.90 accuracy at 69.8 tokens per second, demonstrating strong results from quantized local inference. However, sustained inference workloads produce notable thermal effects: the M5 Max draws 60-90W during operation, with fan noise becoming noticeable after 2-3 minutes, keyboard temperatures reaching 42-45 degrees Celsius, and battery runtime limited to roughly 1.5-2.5 hours. These characteristics suggest that plugged-in operation is recommended for extended inference sessions.

  • Qwen 3.5 122B-A10B (4-bit): ~66/61/55 tok/s at 4K/16K/32K context
  • Qwen2.5 VL 7B: 0.90 accuracy at 69.8 tokens per second
  • Power draw: 60-90W during sustained inference
  • Battery runtime: 1.5-2.5 hours; plugged-in operation recommended

Closing read

Conclusion

The evidence consistently shows that the Apple M5 Max represents a significant advancement in local LLM inference performance on Apple Silicon. Multiple independent sources confirm speed improvements of approximately 28% over the M4 Max, with the chip capable of running 90B+ parameter models locally thanks to its 128GB unified memory configuration. The architectural improvements, particularly the 40 parallel Neural Accelerators with direct memory access, provide tangible performance benefits that translate to faster inference across model sizes. However, readers should note that benchmarking Apple Silicon for LLM inference remains a moving target, with published numbers varying based on quantization level, context length, batch size, and inference framework. The thermal characteristics and power consumption during sustained workloads also suggest that while the M5 Max is powerful, it operates best when plugged in for extended inference sessions. For users planning to invest in hardware that will remain relevant through 2028-2029, the M5 Max appears to be a solid long-term choice for local AI workloads.
